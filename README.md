# sme-web

Landing page jasa pembuatan website UMKM (KreasiWeb) — cepat, rapi di HP, siap SEO, terhubung ke WhatsApp.

## Struktur

- `index.html` — landing page utama (single file, siap deploy ke GitHub Pages / Netlify / Vercel)

## Jalankan lokal

Buka `index.html` langsung di browser, atau jalankan server statis:

```bash
cd sme-web
python -m http.server 8080
# buka http://127.0.0.1:8080
```

## Deploy ke GitHub Pages

Repo ini disiapkan untuk GitHub Pages: push ke branch `main`, lalu aktifkan Pages (Settings → Pages → Deploy from branch → `main` / root).

## Catatan sebelum publikasi

- Ganti nomor WhatsApp `6281234567890` dengan nomor asli (ada di beberapa titik + script form).
- Ganti nama brand `KreasiWeb` bila perlu.
- Ilustrasi foto bersifat dekoratif.
